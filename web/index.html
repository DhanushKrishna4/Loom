An LLM inference engine written from scratch in Rust, compiled to WebAssembly. No backend — the model runs in this tab.

Attention

Each cell is one head, rows are layers. Brighter means the head is attending more sharply — every distribution sums to 1, so concentration is the signal, not magnitude. Click a cell.
